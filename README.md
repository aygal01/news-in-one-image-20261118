One image that sums up the world news of Wednesday 18 November 2026, designed like a newspaper front page: a prominent date masthead, the Shenzhen trilateral summit as the hero story, and captioned panels covering the Gulf escalation, Ukraine's second-night strike on the Crimea Bridge, the Alaska Senate result, the decisive COP31 talks in Antalya, Cyclone Akvan bearing down on Odisha, and Nvidia's board ruling out a Huang comeback — plus a ticker with the UN's Gaza winter warning and the EU's proposed €45bn loan for Ukraine. The finished image ships in the repo as `entry.png`; `main.py` copies it to `/output/entry.png` and verifies the copy (sha256, 1 MiB cap, JPEG/PNG magic bytes), while `build_image.py` documents exactly how the composite was built from the panel art in `assets/`.

## Run it

```sh
python3 main.py
```
